# Gridly

Gridly Web — frontend для управления складом. Оператор работает с картой, роботами, каталогом, заказами и остатками в рабочей области склада.

## Локальный запуск

Требуется Bun 1.4.3. Запустите сервер Gridly на `127.0.0.1:8080` или укажите его адрес в `API_PROXY_TARGET` в `.env.local`.

```sh
bun install --frozen-lockfile
cp .env.example .env.local
bun run dev
```

Для работы с локальным mock-сервером запустите его на порту 4000, затем используйте `bun run dev:mock`.

## Сборка и размещение

Соберите приложение и запустите локальный просмотр.

```sh
bun run build
bun run preview
```
