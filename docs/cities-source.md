# City directory

`src/pages/settings/config/cities.json` contains city names and region labels derived from [HFLabs / DaData city.csv](https://github.com/hflabs/city). Retrieved 2026-11-04. Source fields: city, settlement, region, region_type. Names were deduplicated and sorted; regions distinguish duplicate names.
