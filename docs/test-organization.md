# Организация тестов Gridly

До переноса команда `bun run test` запускала 97 проверок из 31 файла. Файлы лежали рядом с кодом в `src/`, во вложенных папках авторизации и в корневой папке `tests/`.

В обсуждении FSD рекомендуют хранить тесты рядом с кодом соответствующего сегмента, чтобы связанные изменения оставались в одной папке. Допустим и отдельный каталог, повторяющий структуру исходников. Для Gridly выбрали единый каталог `tests/` с группировкой по виду проверки и предметной области. [Обсуждение в репозитории FSD](https://github.com/feature-sliced/documentation/discussions/435)

| Каталог | Что в нём искать |
| --- | --- |
| `tests/unit/` | Проверки отдельных функций и модулей, сгруппированные по предметной области. |
| `tests/integration/` | Проверки взаимодействия модулей, REST-контрактов, SSE и тестовых данных Bruno. |
| `tests/ui/` | Сценарии Chromium и код для запуска браузера и локального сервера. |
| `tests/support/` | Данные и вспомогательный код, которые используют несколько наборов тестов. |

Интеграционные и браузерные тесты читают общие ответы из файла Bruno. [Конфигурация Bruno](../bruno/mocks/Gridly%20API.yml)

## Запуск и проверка типов

- Bun рекурсивно обнаруживает `*.test.ts` и `*.spec.ts`. Аргументы после `bun test` фильтруют файлы по подстроке пути. В Gridly команды `test` и `test:watch` указывают каталоги `tests/unit/` и `tests/integration/`. Для запуска только модульных тестов подходит `bun test ./tests/unit/`. [Поиск тестов в Bun](https://bun.sh/docs/test/discovery)
- `bun run test:ui` запускает `tests/ui/smoke.ts`. Скрипт явно импортирует файлы `tests/ui/scenarios/<сценарий>.ts`, выбирает сценарии и запускает Chromium через API Playwright. [Скрипт Gridly](../tests/ui/smoke.ts) · [Playwright Library](https://playwright.dev/docs/library)
- `tests/tsconfig.json` наследует параметры компилятора приложения. Собственный `include` тестового конфига заменяет список исходных файлов приложения. TypeScript разрешает относительные пути от файла конфигурации, в котором они заданы. Поэтому унаследованный псевдоним `@/*` указывает на корневой `src/` и из тестов. Bun читает `compilerOptions.paths` при разрешении импортов. [Конфигурация тестов Gridly](../tests/tsconfig.json) · [Конфигурация приложения Gridly](../tsconfig.app.json) · [Наследование TSConfig](https://www.typescriptlang.org/tsconfig/#extends) · [Поиск импортов в Bun](https://bun.sh/docs/runtime/module-resolution#path-re-mapping)
